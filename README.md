# リプレイカメラ v0.5.5

[公開URL](https://800lab.github.io/replaycam/)

- 遅れて自動再生、または直前の動きを0.5倍で見返す。5・10・15・20・30秒、初期値10秒。再生位置バーで止めて見られる。描画・AI判定・比較表示・速度選択は追加しない。
- カメラの許可を最初に取得し、届いた映像をためる。途中でカメラを取り直して同じ秒数を待ち直す処理はしない。遅延からのスローは画面に映っていた時点を終点にし、たまった分から見返せる。スロー中はカメラ停止。
- 撮影中のモード・秒数変更では同じカメラと映像を維持し、長い秒数に足りない分だけ待つ。見返し中も区間を消さず、カメラを再開しない。画質・カメラの変更は再起動が必要。
- 通常の対応端末ではJPEG画像を一時保持する方式に統一。標準は最大1280×720・15fps、低めは最大640×360・30fpsを目標とする。カメラ映像が小さい場合は引き伸ばさず、実際の解像度・コマ数は端末と撮影条件による。カメラには最大30fpsを要求するが、露光時間や動きのぶれを保証するものではない。
- 保持映像は最大128MiB・60.8秒。古い分を解放し、同時に処理する圧縮・画像復号はそれぞれ1件まで。通常のJPEG品質は標準0.88/低め0.8、容量枠を超えるフレームだけ最大4回で調整する。ブラウザー・カメラ・描画・動画作成中の内部メモリは保持量とは別。
- 「区間を選んで保存」で、保持済みの最大30秒から同じバーと「ここから」「ここまで」で選ぶ。遅延モードでは画面に映っていた時点までの映像になる。撮影直後は実際にたまった分だけ。
- 「動画を作る」「スローを作る」で選択区間を端末内で動画化。通常は区間と同程度、0.5倍は約2倍の作成時間がかかる。完了後、同じボタンの「動画を保存」「スローを保存」を押して保存する。MP4/H.264を優先し、対応状況によりWebM/VP8。音声なし、撮影した向き、コマ補間なし。
- 出力32MiB・作成時間＋10秒まで、同時作成1件。作成中も「おわる」で中断できる。できた動画の一時URLは1個・60秒までで、新しい動画の完成時と終了時に解放する。保存先と保存可否はブラウザー・端末管理の設定による。写真アプリへの自動登録や提出先との連携はしない。
- 映像は端末内で処理。音声収録・自動保存・アプリからの外部送信・共有なし。「おわる」、タブ非表示・離脱でカメラと一時映像を解放。止めた見返しは操作なし60秒で消去し、再生・動画作成中は途中消去しない。連続撮影の上限は120分。保存済みファイルは「おわる」で消えない。
- JPEG処理が使えない旧ブラウザーには既存の方式を残すが、機能や性能は同一ではない。学校のURL・カメラ・ダウンロード許可、保存動画の再生・提出先との互換性は別々に確認する。実iPad・学校Chromebook・児童操作・実写画質・現方式120分・発熱電池は未確認。PCの合成映像での成功を実機成功とは扱わず、児童映像を開発用に収集しない。

HTML/CSS/JavaScriptのみ。外部ライブラリ・外部API・ビルド工程なし。ローカルはこのディレクトリで `python3 -m http.server 8765 --bind 127.0.0.1`。カメラにはHTTPSまたはlocalhostが必要。
