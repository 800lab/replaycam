# リプレイカメラ v0.5.7

[公開URL](https://800lab.github.io/replaycam/)

- 配色はAzurewoodの青 #2479A9・白 #FFFFFF・墨色 #1D2933 を基調とする。モード選択・設定欄・再生操作のまとまりと余白を整え、44px以上の操作ボタンと映像面積を維持する。機能や操作文は増やさない。

- 遅れて自動再生、または直前の動きを0.5倍で見返す。5・10・15・20・30秒、初期値10秒。再生位置バーで止めて見られる。描画・AI判定・比較表示・速度選択は追加しない。
- カメラの許可を最初に取得し、届いた映像をためる。通常のJPEG対応端末では「とめる」は表示だけを止め、同じ位置の「つづける」で今の遅延表示へ戻る。撮影は続き、「表示停止・撮影中」と表示する。表示停止から60秒で終了する。
- スロー見返し中も同じカメラの映像を保持するため、「もどる」「つぎへ」で撮影を取り直さない。遅延からのスローは見ていたフレームを終点にする。見返し中に画質を変えても過去の映像は消さず、新しく撮影する分へ反映する。カメラが切れた場合は撮影だけ止め、既にある見返しは維持する。
- モード・秒数変更は同じカメラと映像を維持し、長い秒数に足りない分だけ待つ。画質変更も保持画像のサイズ・取得頻度を切り替え、カメラは取り直さない。変更前の映像の画質は変わらず、新画質は遅延秒数を経て表示される。カメラ切替は別の機器を開くため再準備が必要。
- 通常の対応端末はJPEG画像を一時保持する。標準は最大1280×720・15fps、低めは最大640×360・30fps。画質切替時に取り直さないため、入力は両画質とも最大1280×720/30fpsを要求し、実端末の負荷は要確認。小さい入力を引き伸ばさず、実際の解像度・コマ数は端末と条件による。露光や動きのぶれは保証しない。
- 撮影中のローリング保持は最大60.8秒、固定する見返しは最大30秒。所有するJPEG payloadは両方の合計128MiB以内。見返しは変更できないJPEG Blobを独立した管理単位で参照し、同じBlobの重なりも二重に数えて128MiB以内へ制限する。見返し中はその容量を撮影側から差し引くため、戻った直後の保存区間は実際に残っている分だけ。古い分を解放し、同時に処理する圧縮・画像復号はそれぞれ1件まで。通常のJPEG品質は標準0.88/低め0.8、容量枠を超えるフレームだけ最大4回で調整する。ブラウザー・カメラ・描画・動画作成中の内部メモリは保持量とは別。
- 「区間を選んで保存」で、保持済みの最大30秒から同じバーと「ここから」「ここまで」で選ぶ。遅延モードでは画面に映っていた時点までの映像になる。撮影直後は実際にたまった分だけ。
- 「動画を作る」「スローを作る」で選択区間を端末内で動画化。通常は区間と同程度、0.5倍は約2倍の作成時間がかかる。完了後、同じボタンの「動画を保存」「スローを保存」を押して保存する。MP4/H.264を優先し、対応状況によりWebM/VP8。音声なし、撮影した向き、コマ補間なし。
- 出力32MiB・作成時間＋10秒まで、同時作成1件。作成中も「おわる」で中断できる。できた動画の一時URLは1個・60秒までで、新しい動画の完成時と終了時に解放する。保存先と保存可否はブラウザー・端末管理の設定による。iPad/iPhoneのMP4は対応時にOSの保存メニューを開く。「ビデオを保存」を選ぶと写真への保存を試せる。アプリから写真へ自動登録はできず、保存項目や可否はOSの判断。Chromebook/非対応時はダウンロード。提出先との連携はしない。
- 映像は端末内で処理。音声収録・自動保存・アプリからの自動送信なし。iOSの保存メニューにはOSが他アプリへの共有先も表示するが、アプリが宛先を選んだり自動送信したりしない。「おわる」、タブ非表示・離脱でカメラと一時映像を解放。OS保存メニュー中の一時的な非表示では撮影を止め、見返しと作成済みファイルだけを維持するが、操作なし60秒/一時動画60秒の上限と離脱・終了の解放は維持する。止めた見返しは操作なし60秒で消去し、再生・動画作成中は途中消去しない。連続撮影の上限は最初の開始から120分で、画質変更・表示再開・見返し復帰では期限を延ばさない。保存済みファイルは「おわる」で消えない。
- JPEG処理が使えない旧ブラウザーには既存の方式を残すが、機能や性能は同一ではない。学校のURL・カメラ・ダウンロード許可、保存動画の再生・提出先との互換性は別々に確認する。056では本人から確認表示と保存の改善報告あり（保存先/速度種別は未特定）。057の実iPad連続操作・学校Chromebook・児童操作・実写画質・現方式120分・発熱電池は未確認。PCの合成映像での成功を実機成功とは扱わず、児童映像を開発用に収集しない。

HTML/CSS/JavaScriptのみ。外部ライブラリ・外部API・ビルド工程なし。ローカルはこのディレクトリで `python3 -m http.server 8765 --bind 127.0.0.1`。カメラにはHTTPSまたはlocalhostが必要。
